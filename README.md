# 🌍 World War Empire Bot

Telegram bot for the "World War Empire" strategy game.

## Run on Replit
1. Import this repo on Replit.
2. Add a Secret: `BOT_TOKEN` = your Telegram bot token from @BotFather.
3. (Optional) Add Secret `CHANNEL` = `@YourChannel`.
4. Install deps: `pip install -r requirements.txt`
5. Run: `python world_war_empire_bot.py`
